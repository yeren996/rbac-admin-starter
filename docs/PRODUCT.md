# 产品说明：RBAC Admin Starter

## 1. 产品定位

**RBAC Admin Starter** 是一个面向中后台系统的通用权限管理底座，基于 **NestJS + Prisma + PostgreSQL + Vue 3 + Vben Admin web-antd** 构建。它提供登录认证、动态菜单、按钮权限、后端接口权限、用户/角色/菜单/部门管理、审计日志、顶部栏通知、偏好设置和中英文切换等基础能力。

适用场景：

- 企业内部管理后台、运营后台、SaaS 管理端的起步工程；
- 需要快速落地 RBAC 权限模型的业务系统；
- 需要前后端权限闭环、审计日志和可二开工程结构的项目。

## 2. 核心能力

| 能力 | 说明 | 价值 |
| --- | --- | --- |
| 登录认证 | JWT access token + refresh token | 统一保护后端 API，支持登录态刷新 |
| RBAC 权限 | 用户、角色、菜单、按钮权限码 | 支持页面级和按钮级授权 |
| 动态菜单 | 后端按当前用户角色返回路由树 | 菜单不写死在前端，便于后台配置 |
| 接口权限 | `JwtAuthGuard` + `PermissionsGuard` | 前端隐藏按钮之外，后端再次拦截越权请求 |
| 审计日志 | 记录登录和关键系统操作 | 便于追踪操作来源与问题排查 |
| 顶部栏通知 | 基于用户和审计日志生成通知 | 登录后可查看、标记已读、删除和清空通知 |
| 顶部栏设置 | 偏好设置抽屉 | 支持布局、主题、语言、组件开关等个性化配置 |
| 中英文切换 | 顶部栏语言按钮 + 后端本地化菜单 | UI 语言和动态菜单标题可随语言刷新切换 |
| 文档与脚本 | README、产品说明、使用手册、统一命令 | 降低交付、部署和二开成本 |

## 3. 角色与默认账号

| 角色       | 默认账号               | 权限范围                     |
| ---------- | ---------------------- | ---------------------------- |
| 超级管理员 | `admin / Admin@123456` | 拥有所有菜单、按钮和接口权限 |
| 演示用户   | `demo / Demo@123456`   | 默认仅访问概览和个人中心     |

## 4. 功能边界

当前版本是“后台底座”而不是完整业务系统：

- 不内置具体行业业务模块，需按项目需要自行扩展；
- 通知中心使用轻量读模型，通知内容来自当前用户和审计日志，已读/删除状态保存在后端进程内存中；生产环境可替换为数据库、Redis、WebSocket 或消息队列；
- 默认启用单租户种子数据，数据表已预留 `tenantId`，可继续扩展多租户隔离策略；
- 前端模板推广、广告、外部文档/Github 菜单已移除，保留工程依赖和必要开源来源说明。

## 5. 二开建议

1. **先建模**：新增业务表时优先考虑 `tenantId`、`createdAt`、`updatedAt`、`deletedAt`。
2. **再授权**：新增页面同步新增 `MENU` 权限，新增按钮同步新增 `BUTTON` 权限码。
3. **前后端同时校验**：前端控制按钮展示，后端接口必须加 `@RequirePermissions()`。
4. **保留审计**：新增关键写操作建议调用 `AuditLogsService.record()`。
5. **保持最小改动**：业务模块放到 `backend/src/<module>` 和 `front/src/views/<module>`，避免修改核心包。
