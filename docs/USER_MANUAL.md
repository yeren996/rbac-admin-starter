# 使用手册：RBAC Admin Starter

## 1. 启动系统

```bash
pnpm install
cp backend/.env.example backend/.env

docker compose up -d postgres
pnpm rbac:init
pnpm dev:api
pnpm dev:admin
```

访问地址：

- 前端：<http://localhost:5555>
- 后端 API：<http://localhost:3000/api>
- Swagger：<http://localhost:3000/api/docs>

## 2. 登录

默认账号：

| 账号    | 密码           | 说明       |
| ------- | -------------- | ---------- |
| `admin` | `Admin@123456` | 超级管理员 |
| `demo`  | `Demo@123456`  | 演示用户   |

登录后进入概览页。若接口返回登录过期，系统会按配置跳转登录页或弹出重新登录窗口。

## 3. 顶部栏功能

| 功能 | 操作 | 说明 |
| --- | --- | --- |
| 设置 | 点击齿轮图标 | 打开偏好设置抽屉，可调整布局、主题、语言、部件显示等 |
| 中英文切换 | 点击语言图标 | 选择 `中文` 或 `English`，系统会刷新页面并重新拉取本地化菜单 |
| 通知 | 点击铃铛图标 | 查看通知、标记已读、全部已读、删除单条或清空通知 |
| 用户菜单 | 点击头像 | 进入个人中心、锁屏或退出登录 |

## 4. 用户管理

路径：`系统管理 -> 用户管理`

常用操作：

1. 新增用户：填写用户名、昵称、密码、部门等信息；
2. 编辑用户：修改昵称、邮箱、手机号、部门或状态；
3. 分配角色：给用户绑定一个或多个角色；
4. 重置密码：管理员可为用户设置新密码；
5. 禁用用户：禁用后该用户不可继续正常使用系统。

## 5. 角色管理

路径：`系统管理 -> 角色管理`

角色用于聚合菜单和按钮权限：

1. 新增角色，填写角色编码和名称；
2. 点击分配菜单，选择该角色可访问的页面和按钮；
3. 给用户分配角色后，用户重新登录即可获得对应权限；
4. 系统内置角色不建议随意删除。

## 6. 菜单管理

路径：`系统管理 -> 菜单管理`

菜单类型：

| 类型        | 用途                                                 |
| ----------- | ---------------------------------------------------- |
| `DIRECTORY` | 目录分组，不直接对应页面                             |
| `MENU`      | 页面路由，需要填写 `path`、`component`、`permission` |
| `BUTTON`    | 按钮/接口权限码，不显示为左侧菜单                    |

新增页面时，前端页面文件路径需要与菜单 `component` 对应。例如：

```txt
front/src/views/business/order/index.vue
```

菜单配置可填写：

```txt
component: /business/order/index
permission: business:order:list
```

## 7. 部门管理

路径：`系统管理 -> 部门管理`

用于维护组织结构。用户可绑定部门，后续二开业务可按部门扩展数据范围、审批链或统计维度。

## 8. 审计日志

路径：`系统审计 -> 操作日志`

审计日志记录登录和关键管理操作，包含操作者、请求方法、接口路径、响应状态和耗时。排查异常权限、接口失败或误操作时优先查看该页面。

## 9. 个人中心

路径：头像菜单 -> 个人中心

可维护基础资料、修改密码和查看安全/通知设置。建议首次部署后立即修改默认管理员密码。

## 10. 常见问题

| 问题 | 处理方式 |
| --- | --- |
| 登录失败 | 检查后端是否运行、数据库是否已 seed、账号密码是否正确 |
| 菜单为空 | 确认用户已分配角色，角色已分配菜单权限 |
| 按钮不显示 | 检查按钮 `BUTTON` 权限码是否授权给当前角色 |
| 接口 403 | 后端 `@RequirePermissions()` 要求的权限码未授权给当前用户 |
| 切换语言后菜单未变化 | 使用顶部栏语言按钮切换，系统会刷新并按 `Accept-Language` 重新拉取菜单 |
